# NovaPlay Apps & Games Store

A frontend-only apps and games store built with plain HTML, CSS, and JavaScript.

## Features

- Responsive landing page and catalog layout
- Search, category filters, and sorting
- App/game detail modal
- Saved-items library drawer using `localStorage`
- Mobile navigation menu
- Curated collections and promotional deals sections

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
