# GamesappTry

A front-end only apps and games store built with plain HTML, CSS, and JavaScript.

## What is included

- Responsive landing page with a featured product hero
- Searchable and filterable app/game catalog
- Sort controls for rating, downloads, and price
- Quick filters for free, premium, editor picks, and offline products
- Product detail modal previews
- Wishlist toggles, add-to-cart actions, and bundle deal interaction

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.
